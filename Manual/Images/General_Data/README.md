# General Electrical Technical Reference Files
Category: Basic Electrical Data

This directory contains the engineering data extracted from the general electrical reference images:

## File Index:
- `basic_electrical_formulas.txt`: Complete Ohm's law circle, single-phase, three-phase active/reactive/apparent power formulas.
- `voltage_drop_and_cable_sizing.txt`: IEC 60364-5-52 current carrying capacities for copper conductors, resistance tables, and voltage drop formulas.
- `wiring_color_codes_and_ip_ratings.txt`: IEC and NEC conductor identification colors and IEC 60529 Ingress Protection ratings.
