# Motor Technical Reference Files
Category: Motor Engineering Data

This directory contains the detailed engineering data extracted from the motor reference images:

## File Index:
- `motor_flc_ratings_iec_nec.txt`: Full load current tables from 0.37 kW to 200 kW across all voltage levels (220V - 690V).
- `motor_connections_star_delta.txt`: Winding lead markings, dual-voltage configurations, and terminal box bridging bars.
- `motor_power_factor_capacitor_sizing.txt`: Capacitor bank reactive power formulas, microfarad per phase sizing, and overload relay adjustments.
- `motor_troubleshooting_and_starting.txt`: Locked rotor current, direct-on-line vs star-delta starting torque and current reduction.
