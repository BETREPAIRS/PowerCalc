# Transformer Technical Reference Files
Category: Transformer Engineering Data

This directory contains the detailed engineering data extracted from the transformer reference images:

## File Index:
- `transformer_ratings_and_currents.txt`: Full load current tables from 15 kVA to 3150 kVA across low and medium voltage systems.
- `transformer_short_circuit_and_impedance.txt`: Short circuit current calculations, %Z impedance ratings, and breaking capacity requirements.
- `transformer_vector_groups_and_windings.txt`: Vector groups (Dyn11, Dyn5, Yyn0, Dd0), terminal markings, and clock notations.
- `transformer_losses_and_tap_changers.txt`: No-load and load loss equations, maximum efficiency load factor, and tap changer step settings (+/- 2.5%, +/- 5%).
