# Field Demonstration Videos Reference & Procedures
Category: Practical Video Guides

This directory contains procedural transcripts, testing sequences, and safety instructions for the 11 uploaded engineering demonstration videos:

## Video Reference Guide Index:
1. `VID_01_star_delta_starting.txt`: Contactor changeover sequence, interlock timings, and inrush reduction.
2. `VID_02_motor_insulation_testing.txt`: Megger testing between phases and phase-to-ground with 500V/1000V DC.
3. `VID_03_motor_terminal_box_bridging.txt`: Visual step-by-step for Star and Delta terminal strip links.

5. `VID_05_transformer_insulation_and_pi.txt`: Polarization Index (PI) and 10-minute Megger testing on oil-immersed transformers.
6. `VID_06_transformer_turns_ratio.txt`: TTR test procedures and percentage error criteria (< 0.5%).
7. `VID_07_transformer_tap_changer.txt`: De-energized tap changer operation and contact resistance check.
8. `VID_08_multimeter_and_clamp_meter.txt`: Safe True-RMS current, line-to-line, and line-to-neutral measurements.
9. `VID_09_phase_sequence_indicator.txt`: Verifying clockwise A-B-C phase rotation before motor energization.
10. `VID_10_earth_ground_testing.txt`: 3-point fall-of-potential earth ground resistance measurement (62% rule).
11. `VID_11_thermal_imaging_inspection.txt`: Infrared thermography guidelines for electrical panels and terminal lugs.
